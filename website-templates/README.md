# Open Website Templates

Folder ini berisi template HTML statis buatan Razzaq Ventures yang dapat dibuka langsung tanpa proses build dan tanpa koneksi database. Salinan preview juga tersedia di `public/website-templates/` agar dapat dibuka dari website Library. Katalog preview tersedia di `public/website-templates/index.html`.

## Templates

- `company-profile/index.html` — starter company profile untuk bisnis dan layanan profesional.
- `product-landing/index.html` — starter landing page produk dan brand.
- Source proyek klien HERU BALI TOUR berada terpisah di `projects/client-work/heru-bali-tour/`; bukan bagian dari lisensi template terbuka dan tidak boleh digunakan ulang atau didistribusikan tanpa izin klien.

## Cara pakai

Buka file `index.html` langsung di browser. Ganti seluruh placeholder seperti nama, deskripsi, tautan, nomor WhatsApp, spesifikasi, dan identitas visual. Periksa aksesibilitas, tampilan mobile, hak penggunaan foto, serta kebenaran klaim bisnis sebelum dipublikasikan.

Template HTML statis original dalam folder `public/website-templates/` tersedia di bawah lisensi MIT yang disertakan pada folder ini. Lisensi tidak berlaku untuk source client-work HERU BALI TOUR, foto eksternal, font eksternal, logo, merek dagang, atau aset pihak ketiga.
